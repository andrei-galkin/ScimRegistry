# ScimRegistry
ScimRegistry is a high-performance SCIM 2.0 server built in Go. It automates the user lifecycle—onboarding, profile updates, and secure deprovisioning—by syncing your app with IdPs like Okta and Entra ID. Fully compliant with RFC 7643 &amp; 7644, it provides a fast, scalable way to manage identity provisioning in cloud-native environments.
